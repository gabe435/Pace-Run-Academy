🏃‍♂️ Pace Run Academy

Projeto desenvolvido para a disciplina de Design Digital. O Pace Run Academy é uma plataforma web criada com foco na experiência do usuário para apresentar uma instituição de corrida voltada para alta performance, rotina e bem-estar.

🔗 Acesse o projeto: Pace Run Academy - GitHub Pages
📌 Sobre o Projeto

O site foi desenvolvido do zero utilizando HTML5 e CSS3, prezando por uma estrutura semântica, design moderno e navegação simples.
📄 Páginas do Site

    index.html (Homepage): Página inicial de boas-vindas, destacando o propósito da instituição e os principais atrativos visuais.

    sobre.html (Sobre a Instituição): Apresenta a história, missão, visão, valores e a proposta de valor da Pace Run Academy.

    contato.html (Contato): Formulário interativo para que os usuários entrem em contato enviando nome e e-mail.

🛠️ Tecnologias Utilizadas

    HTML5: Estrutura e semântica web.

    CSS3: Estilização, layout e tipografia.

    GitHub Pages: Hospedagem e deploy do projeto.

🚀 Como Rodar o Projeto Localmente

    Clone este repositório:

    git clone https://github.com/gabe435/Pace-Run-Academy.git

    Navegue até a pasta do projeto.

    Abra o arquivo index.html em qualquer navegador.
