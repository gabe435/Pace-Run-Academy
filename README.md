# 🏃‍♂️ Pace Run Academy

Projeto desenvolvido para a disciplina de Design Digital. O **Pace Run Academy** é uma plataforma web responsiva desenvolvida com foco no design, usabilidade e experiência do usuário para uma instituição de corrida voltada para alta performance, rotina e bem-estar.

🔗 **Acesse o projeto:** [Pace Run Academy - GitHub Pages](https://gabe435.github.io/Pace-Run-Academy/)

---

## 📌 Sobre o Projeto

O site evoluiu de uma estrutura base em HTML5/CSS3 para uma aplicação totalmente responsiva utilizando o framework **Bootstrap 5.3**. O design preserva a identidade visual original da marca (tons de verde floresta, fundo bege e tipografia refinada), garantindo excelente navegação tanto em dispositivos móveis (smartphones) como em desktops.

---

## 📄 Páginas e Estrutura do Site

* **`index.html` (Homepage):** Página inicial com destaque para o propósito da instituição, botão de pré-inscrição com janela modal e carrossel interativo de galeria de fotos.
* **`sobre.html` (Sobre a Instituição):** Apresenta a história, missão, valores, atendimento e um menu interativo estilo *Accordion* com os 5 motivos para se juntar à academia.
* **`contato.html` (Contato):** Formulário de contato integrado via Web3Forms com validação visual e caixas informativas de atendimento.
* **`style.css`:** Estilos e variáveis personalizadas integrados com o ecossistema do Bootstrap.

---

## 🛠️ Tecnologias e Recursos Utilizados

* **HTML5:** Estruturação semântica da web.
* **CSS3:** Estilização personalizada, variáveis de cores e ajustes de layout.
* **Bootstrap 5.3:** Framework front-end para responsividade e componentes visuais.
* **GitHub Pages:** Hospedagem e *deploy* contínuo do projeto.

### 🎨 Recursos e Componentes Bootstrap Aplicados:
1. **Navbar Responsiva:** Menu com *toggler* (botão hambúrguer) para telas de celular.
2. **Sistema de Grid Flexível:** Layout adaptável (`container`, `row`, `col-*`).
3. **Carrossel de Imagens (Carousel):** Galeria interativa de treinos com legendas e indicadores.
4. **Janela Modal (Modal Pop-up):** Formulário interativo de pré-inscrição na Homepage.
5. **Accordion:** Lista expansível para apresentação dos motivos da academia na página *Sobre*.
6. **Cards:** Organização de blocos visuais para apresentação de conteúdos.
7. **Badges / Selos:** Destaques textuais e categorização das seções.
8. **Form Controls & Floating Labels:** Campos de formulário com rótulos flutuantes modernos.
